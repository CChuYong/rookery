## rookery v1.0.1

v1.0.1 makes the Claude default model follow the model Claude recommends for your account. It also catches up with Codex CLI 0.170.0 and its new models, and fixes a small rendering bug in inline code.

_7 commits since v1.0.0._

### 🧠 Claude default model follows the recommendation

- **Before:** new sessions and workers always started on Opus 4.8 unless you had saved a model in Settings.
- **Now:** rookery asks the Claude Agent SDK which model it recommends for your account and uses that. Today that is **Opus 5.5**. This is the same model Claude Code picks by default, so it follows your plan and new releases without a rookery update.
- **In Settings → Models**, both Claude model lists start with **Recommended (Opus 5.5)**.
  - Leave it selected to keep following the recommendation.
  - Pick a specific model to pin it.
  - Choose Recommended again to go back.
- **Which model wins:** a model saved in Settings first, then `ROOKERY_MASTER_MODEL` / `ROOKERY_WORKER_MODEL`, then the recommendation.
- Opus 4.8 is used only in the brief moment after the daemon starts, before the recommendation is known.

### 🤖 Codex CLI 0.170.0

- **New models priced:** `gpt-6.2-sol` and `gpt-6.2-astra`, for both Standard and Fast, from the official pricing page. Before this, their cost showed as unavailable and cost budgets could not see them.
- **Codex default model** is now `gpt-6.2-sol`, matching Codex's own new default. It costs the same as `gpt-6.1-sol`. A model you saved in Settings is unchanged.
- **Compatibility:** rookery is verified against Codex CLI 0.170.0. The minimum supported version is still 0.169.0.

### 🧹 Fixes

- Inline code such as `node --test` no longer renders as `node--test`. The code font's `--` ligature was hiding the space before it.

### 📖 Docs

- The README has new screenshots of the current app and an updated feature overview.

### 📦 Notes

- macOS builds are signed and notarized.
- Linux AppImage and unsigned Windows installer builds are included in the release assets.
- Updater metadata and stable latest-download filenames are published for all supported desktop platforms.
